# Mode "Pitch Deck" - Documentation Complète

## 🎯 Vue d'ensemble

Le mode **Pitch Deck** est une fonctionnalité révolutionnaire qui **génère automatiquement des présentations professionnelles** basées sur vos idées. Transformez vos concepts en pitches convaincants en quelques clics.

---

## ✨ Fonctionnalités principales

### 1. **Génération Automatique**
- Sélectionnez une idée existante
- Le système génère automatiquement un pitch deck complet avec 8 slides professionnelles
- Aucune configuration requise - tout est pré-rempli intelligemment

### 2. **Structure Pitch Deck Optimisée**
Le pitch deck contient 8 slides stratégiquement conçues :

1. **Titre** (Title Slide)
   - Présentation du concept
   - Taglines inspirants
   
2. **Le Problème** (Problem)
   - Identification des défis du marché
   - Points de douleur clients
   
3. **Notre Solution** (Solution)
   - Votre approche unique
   - Bénéfices clés
   
4. **Opportunité de Marché** (Market Opportunity)
   - Taille du marché adressable
   - Potentiel de croissance
   
5. **Modèle Commercial** (Business Model)
   - Flux de revenus
   - Structure des coûts
   
6. **Traction & Métriques** (Traction)
   - KPIs importants
   - Jalons atteints
   
7. **L'Équipe** (Team)
   - Expertise du leadership
   - Réseau et connexions
   
8. **L'Appel à Action** (Closing)
   - Demande d'investissement
   - Prochaines étapes

### 3. **Édition Flexible**
- Modifiez chaque slide individuellement
- Éditez le contenu et les points clés
- Personnalisez votre pitch pour différents publics
- Sauvegardez vos modifications en temps réel

### 4. **Gestion des Pitches**
- Créez plusieurs pitches à partir de la même idée
- Visualisez tous vos pitches générés
- Supprimez les pitches obsolètes
- Accédez facilement à vos créations précédentes

---

## 🚀 Comment utiliser

### Étape 1 : Accéder au Mode Pitch Deck
1. Ouvrez l'application
2. Cliquez sur l'onglet **"Pitch Deck"** dans la barre de navigation inférieure
3. Vous verrez deux sections : **Generate** et **My Decks**

### Étape 2 : Générer un Pitch
#### Option A : Depuis la Liste des Idées
1. Allez dans l'onglet **"Generate"**
2. Consultez la liste de toutes vos idées
3. Cliquez sur le bouton **"Generate"** à côté de l'idée que vous souhaitez pitcher
4. Le système génère automatiquement un pitch deck complet

#### Option B : Export Direct depuis une Idée
> À bientôt : Bouton d'export directement depuis la page Kanban

### Étape 3 : Visualiser Votre Pitch
- Le pitch deck s'ouvre automatiquement dans une visionneuse dédiée
- Naviguez entre les slides avec les boutons **Suivant** et **Précédent**
- Consultez la barre de progression pour suivre votre avancement

### Étape 4 : Éditer Votre Pitch
1. Cliquez sur le bouton **éditer** (crayon) en haut de chaque slide
2. Modifiez le contenu principal et les points clés
3. Cliquez sur **"Save Changes"** pour valider vos modifications

### Étape 5 : Accéder à Vos Pitches
1. Allez dans l'onglet **"My Decks"**
2. Consultez tous vos pitches générés
3. Cliquez sur un pitch pour le visualiser
4. Utilisez le menu **⋯** pour :
   - Voir le pitch
   - Supprimer le pitch
   - (Prochainement) Partager le pitch
   - (Prochainement) Exporter en PDF/PowerPoint

## 📊 Anatomie d'une Présentation

### Types de Slides
Chaque slide est typée pour une utilisation optimale :

| Type | Utilisation | Audience |
|------|-------------|----------|
| Title | Accroche initiale | Tous |
| Problem | Contextualiser l'enjeu | Investors, Partners |
| Solution | Valeur ajoutée | Clients, Investors |
| Market | Opportunité commerciale | Investors |
| Business | Viabilité financière | Investors |
| Traction | Preuves de concept | Investors |
| Team | Crédibilité | Investors |
| Closing | Appel à l'action | Tous |

```
┌─────────────────────────────────────┐

│                                     │

│                                     │
├─────────────────────────────────────┤
│ Clés Éléments:                      │
│ • Point 1                           │
│ • Point 2                           │
│ • Point 3                           │
└─────────────────────────────────────┘
```

## 💡 Bonnes Pratiques

### Pour un Pitch Efficace

1. **Soyez Concis**
   - Limitez le contenu principal à 1-2 paragraphes
   - Utilisez des puces pour la clarté

2. **Racontez une Histoire**
   - Commencez par un problème (slide 2)
   - Proposez votre solution (slide 3)
   - Montrez l'impact (slides 4-6)

3. **Adaptez votre Audience**
   - Pour les investors : insistez sur le marché et le business
   - Pour les clients : mettez l'accent sur la solution
   - Pour les partenaires : montrez la traction

4. **Utilisez des Données**
   - Incluez des chiffres concrets
   - Citez vos sources
   - Montrez vos résultats

5. **Peaufinez vos Slides**
   - N'acceptez pas les valeurs par défaut
   - Personnalisez chaque point clé
   - Vérifiez la cohérence

## ⚙️ Configuration Technique

### Architecture

```
PitchDeckScreen
├── _buildGenerateTab()
│   └── ListView des idées disponibles
├── _buildMyDecksTab()
│   └── ListView des pitches créés
└── PitchDeckViewerScreen
    ├── PageView (navigation entre slides)
    ├── PitchSlideWidget (affichage/édition)
    └── Navigation Controls
```

### État Management
- **Provider** : PitchDeckProvider gère l'état global
- **State Local** : Édition locale dans les widgets

### Modèles de Données

#### PitchDeck
```dart
{
  id: int,
  ideaId: int,
  userId: String,
  title: String,
  subtitle: String,
  description: String,
  slides: List<PitchSlide>,
  createdAt: DateTime,
  updatedAt: DateTime,
  targetAudience: List<String>,
  duration: int // minutes
}
```

#### PitchSlide
```dart
{
  type: PitchSlideType,
  title: String,
  content: String,
  bullets: List<String>
}
```

# Quick Start - Mode Pitch Deck

## 🎯 30 Secondes pour Commencer

### 1. Générer
```
Onglet Pitch Deck → Generate → Sélectionner une idée → Bouton "Generate"
```

### 2. Visualiser
```
Le pitch deck s'ouvre automatiquement
Navigation: Boutons Précédent/Suivant
```

### 3. Éditer
```
Clic sur l'icône Éditer (crayon) → Modifier contenu → "Save Changes"
```

### 4. Gérer
```
Onglet "My Decks" → Voir tous vos pitches → Menu ⋯ pour options
```

---

## 📋 Structure du Pitch Deck (8 Slides)

| # | Slide | Contenu |
|---|-------|---------|
| 1 | **Titre** | Présentation + Taglines |
| 2 | **Problème** | Défis du marché + Pain points |
| 3 | **Solution** | Votre approche + Bénéfices |
| 4 | **Marché** | TAM + Potentiel de croissance |
| 5 | **Business** | Revenus + Coûts + Profit |
| 6 | **Traction** | KPIs + Jalons |
| 7 | **Équipe** | Leadership + Expertise |
| 8 | **Closing** | Appel à action + Prochaines étapes |

---

## 🎨 Personnalisation

- Modifiez chaque slide individuellement
- Changez le titre, le contenu et les points clés
- Gardez vos modifications en temps réel

---

## 💾 Sauvegarde

- Tous les pitches sont sauvegardés automatiquement
- Accédez à l'onglet "My Decks" pour consulter l'historique
- Supprimez les pitches dont vous n'avez plus besoin
